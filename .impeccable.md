## Design Context

### Users
A small, closed group of friends (Dima and a handful of others) predicting Champions League match outcomes against each other. Everyone knows everyone; this is a friendly, ongoing competition, not a public product. Users open the app on their own initiative (pull, not push) — there is no notification/digest delivery model to design for, everything is discovered inside the app. (This project is a fork of a Worldcup2026 sibling app for the same friend group — same audience, different tournament.)

### Brand Personality
"Energy and drama — broadcast, power, colorful." Confirmed by the user directly (2026-08-09) when asked how the app should feel. Think live match-day broadcast graphics — kinetic, high-impact, a little theatrical — rather than a plain admin dashboard, while staying legible for quick daily check-ins.

### Aesthetic Direction
- Theme: dark navy base with **blue** accents (`#097adc` primary blue, `#0d2a6e` deep navy) — NOT gold. (Gold/`#FFD700` was the old Worldcup2026 palette; this project has already moved to blue branding — see `AppBackground.jsx`, `index.html` theme-color, the CL "starball" trophy asset. Code comments referencing "gold" in this project are stale copy-paste leftovers from the WC fork, not the actual current design.)
- Fonts already loaded and available (`index.html`): Bebas Neue, Orbitron, Syne, Outfit, Russo One, Black Han Sans, Oswald. Outfit is the current body font; the others are underused display/numeral candidates worth leaning on harder for a bolder redesign.
- Motion: framer-motion for entrance choreography (staggered fades/springs), floating blue particle canvas background (`AppBackground`), marquee/ticker patterns for rounds and insights.
- RTL Hebrew UI throughout.
- Existing surface language leans heavily on glassmorphism (blurred glass panels, glass score-input pills) — per the user's "colorful/energetic" direction and impeccable's own anti-pattern guidance (glassmorphism-everywhere is an overused AI-design tell), new work should actively look for chances to move away from glass-panel-as-default and toward bolder, more graphic/broadcast-poster treatments instead of softly blurred surfaces.
- No specific anti-reference given by the user (asked directly, none volunteered) — default to impeccable's standard bans (no gradient text, no side-stripe borders, no glassmorphism-as-default) as the working anti-references.

### Design Principles
1. Broadcast-grade drama over utilitarian dashboard — treat scores and results as moments to present, not just report.
2. Colorful and kinetic, but with ONE clear point of view per surface — per the user's "energy/drama" brief, prefer bold committed choices (strong color, strong type, real motion) over another soft multi-color glass gradient.
3. Everything is pull, not push — screens must reward a self-initiated visit; no need to design for external notification/preview surfaces.
4. Stay legible at a glance — despite the theatrical tone, a friend checking in for 10 seconds should immediately grasp "what happened" and "where do I stand."
5. RTL-first, dark-first — all layouts and motion must work natively in Hebrew RTL on the navy/blue dark theme.
